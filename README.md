# IPLC 专线供应商：三类商家怎么分、价格差在哪，附 MKCloud 全套餐价目与避坑清单

搜“IPLC 专线供应商”的人，通常卡在同一个地方：这个市场里既有电信联通这样的运营商，也有卖云主机、卖 VPS 的商家，价格从每月一百多到每月几万都有，看起来完全不是一个东西。这篇文章把这三类供应商讲清楚，再以目前做跨境电商专线比较活跃的 MKCloud（Mkcloud）为例，把它的全线套餐、价格口径和购买前的注意事项整理出来，帮你按自己的业务对号入座。

## 先说结论：你找的“供应商”其实分三种

同样叫 IPLC，商家卖给你的东西可能完全不同，先分清楚再看价格，不然很容易拿苹果比橘子。

**第一类是基础运营商。** 中国电信、联通、移动都提供传统 IPLC/MPLS 国际专线，点对点交付，稳定性和合规性最高，但开通流程重、按月固定带宽计费，费用通常到每月数千甚至更高，主要面向有明确合规要求的企业客户。

**第二类是云厂商和 SD-WAN 服务商。** 通过云网络或软件定义的方式实现跨境加速，按云资源和服务付费，灵活度介于运营商和 VPS 商家之间，适合已经把业务放在云上的团队。

**第三类是专线 VPS 商家，MKCloud 属于这类。** 他们把 IPLC、IEPL 跨境段包装成一台台 VPS 出售，每台机器配一个独立入口 IP 和一个独立出口 IP，你连入口、程序从出口发起访问，月付一两百元就能起步。注意这是 VPS 形态，不是能拉进办公室的裸线路，也不是用来建站的云主机。

三类没有绝对优劣，取决于你的规模：有合规刚需和预算，走运营商；业务在云上，看云商；中小卖家、个人开发者、需要低成本出海的业务，专线 VPS 是目前门槛最低的一档。

## IPLC 到底是什么，商家卖给你的又是什么

IPLC 全称 International Private Leased Circuit，国际私有租用线路，本质是点对点的专用电路，与公网隔离。走这条通道的流量不经过公共互联网的跨境节点，所以延迟稳、丢包少，受公网波动影响小。

但拿到你手上的形态，各家差别很大。运营商给的是一条裸线路，需要你自己接入和配置；而 MKCloud 这类商家交付的是已配置好网络路径的 VPS：入口在国内指定省份（比如广州、上海、厦门），出口在香港、日本或美国，每台 VPS 独立分配一入一出两个 IP。

有一个限制必须提前知道：**出口只用于向外访问，不支持外部连入**。官方文档明确说它不适合做公开网站、支付回调、邮件接收或游戏服务端。这个产品是给“服务器主动出海”的场景用的，比如店铺后台操作、素材上传、直播推流、调用海外 API。

## 挑供应商之前，先把这几个口径问清楚

不管最终买谁家的，下面这些问题都值得在付款前确认一遍。这几条同时也是 MKCloud 官方知识库自己反复强调的口径，可以把它们当作判断一家供应商文档是否规范的参照。

1. **交付形态**：是裸线路还是 VPS？出口能不能接收流量？这决定了它能干什么、不能干什么。
2. **延迟口径**：商家标注的通常是“端内延迟”（国内入口到跨境出口那一段），不是你本地到目标网站的全程耗时。广港 1~2ms 不等于你 ping Google 只有 2ms。
3. **共享还是独享**：共享带宽按峰值卖，不保证持续跑满；独享按配置速率卖，速率恒定但数字小。沪港入门为例：共享 200Mbps 峰值、1024GB 月流量、月付 288 元；独享 5Mbps、不限流量、月付 388 元。短时突发上传看共享峰值，长时间持续传输才需要独享。
4. **流量怎么算**：MKCloud 的计量型套餐按上行、下行双向统计，超量后暂停，可以买流量重置或补差价升级。“不限流量”的独享款也受配置速率约束。
5. **IP 情况**：独享 IP 不保证原生、住宅或流媒体解锁，也不等于账号防关联。
6. **实名与合规**：MKCloud 的 IPLC/IEPL 产品需要国内手机号实名认证，这也是这类国内商家的通行门槛。
7. **退款和 SLA**：MKCloud 仅支持开通 24 小时内的质量问题退款，需要提交测试数据，默认产品没有 SLA 保证。
8. **升降级规则**：升级降级走工单，降级到更低价格套餐时差价不退。

## 从下单到开通的流程

1. **注册并实名**。IPLC/IEPL 产品需要国内手机号实名认证，没有国内手机号基本买不了。
2. **选线路和套餐**。按目标市场和入口省份选，比如人在深圳就优先看广港、深港方向。
3. **优惠码试算**。购物车里输入码，确认折扣生效再付款。
4. **等待开通**。官方口径是现货约 1 分钟自动开通，实际受支付和库存影响。每台 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP。
5. **24 小时内测试**。这是唯一的退款窗口，按官方条款，退款只针对质量问题，需要在工单里提交具体数据（延迟、丢包、速度截图），由商家审核判断，不支持“我不想要了”这类主观理由，开通后也不能换成其他地域的产品。
6. **留存测试记录**。iperf3 测吞吐、ping/mtr 测路由，保存时间戳和两端信息，日后报障也用得上。

> 退款要点：24 小时内 + 质量问题 + 测试数据，三者缺一不可。开通前想清楚线路方向，开通后第一时间把该测的都测了。

## 第三方测评里提到的优缺点

第三方评测对 MKCloud 的正面反馈主要集中在延迟和 IP 质量：有评测仓库给出深圳 ping 广港 2~4ms 的实测记录，认为 3ms 左右的端内延迟在对应价位段里表现突出；有评测提到其香港出口在 Scamalytics 的评分很低，出口资源中包含与 Google、Cloudflare 等的 PNI 对接信息（官方宣传口径，不代表访问所有目标都走私有直连）。

需要留意的两点：一是售后以工单为主，有测评提到响应速度一般，重要业务要给报障留出时间余量；二是共享带宽是峰值、双向计流量，如果你的业务是每天十几个小时持续推流或传输，要么算好流量账，要么直接看独享款。

## 常见问题

**IPLC 和 IEPL 到底选哪个？** MKCloud 自己的选型文档说得很直白：不要因为名字给稳定性和价格排高低。实际差异在于线路方向——广港是 IEPL，沪港、沪日、沪美是 IPLC，先按目标市场定方向，再按流量和带宽选档。

**专线 VPS 能建站吗？** 不能。出口不支持外部连入，不能承接公开网站、支付回调或邮件。

**一百多块的和几千块的专线是真假的区别吗？** 不是。差价来自带宽模式、流量额度、接入条件和服务范围，不能用价格判断线路真假，官方文档甚至专门写了“不能凭 Traceroute 跳数鉴定专线”的说明。

**多账号就一定要独享带宽吗？** 不一定。官方明确说共享与独享只区分带宽模式，每台 VPS 的出入 IP 都是独立的，独享带宽也不保证账号不关联。
